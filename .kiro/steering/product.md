# Product Overview

A web-based 3D tic-tac-toe game. Two players take turns locally (pass-and-play) placing X and O pieces on a 3x3 board rendered in 3D. The game detects wins, draws, and allows restarting.

## Core Features

- 3D rendered game board with interactive cells
- Turn-based local multiplayer (X and O)
- Win/draw detection with visual feedback
- Animated piece placement (pieces drop onto the board)
- Win line highlight animation
- Camera orbit controls so players can rotate around the board
- Clean, minimalist visual style with subtle lighting
- Game reset / new game functionality

## Non-Goals (for now)

- No AI opponent (local two-player only)
- No online multiplayer
- No user accounts or persistence
- No sound effects
